# NotebookLM — Trilha de Estudos em Programação (DIO)

Este projeto documenta a criação de um ambiente estruturado de estudos utilizando o NotebookLM para organizar o aprendizado em programação, baseado na metodologia da plataforma DIO e em fontes técnicas complementares.

---

## 🎯 Objetivo

Criar um sistema contínuo de estudos focado em:

- Lógica de programação  
- Organização do aprendizado  
- Revisão ativa com flashcards  
- Planejamento por meio de cronograma  
- Acompanhamento de progresso  
- Construção de portfólio no GitHub  

---

## 🛠 Ferramentas Utilizadas

- NotebookLM (Google)  
- Plataforma DIO.me  
- GitHub  
- Metodologia de estudo ativo  

---

## 📚 Estrutura Criada no NotebookLM

Dentro do NotebookLM foram configurados os seguintes recursos:

- ✅ Mapa mental de lógica de programação  
- ✅ Organização das fontes técnicas  
- ✅ Flashcards automáticos  
- ✅ Questionário (teste de conhecimento)  
- ✅ Relatórios de estudo
